# Roadster / Kickflip

**2.4.4 опубликована**: [игра](https://gleb20.github.io/roadster-kickflip/?v=2.4.4). Узнаваемый улыбающийся Джо, целые наушники и отдельный микрофон; [источники, проверки и откат](docs/verification/2026-10-16-v2.4.4/README.md).

Canonical game: https://gleb20.github.io/roadster-kickflip/

An online Canvas 2D game with native JavaScript ES modules and a DOM UI. No runtime framework, CDN dependency, bundler or generated standalone HTML copies. `index.html` is the single web entry point and contains the critical inline SVG loader/styles. Game and loading logic live in `src/`; a small inline module reports bootstrap failures.

## Development

Node 20+:

```sh
npm run dev
npm test
```

The server listens at http://127.0.0.1:8766. Publish this directory at the GitHub Pages repository root. Keep the original PNG atlases and obstacle-photos.png at their existing paths.

## Code ownership

- `src/clock.js`: fixed 120 Hz simulation clock; visible pause after a long interruption.
- `src/physics.js`: movement constants, analytic jump, collision bounds and pair clearance.
- `src/catalog.js`, `src/director.js`: obstacle definitions and progressive waves.
- `src/characters.js`: complete character silhouettes, animated limbs, shoes and cleaned head sprites.
- `src/props.js`: cached paper props and South Park-inspired couch family.
- `src/photo-cutouts.js`: shared photographic vehicle atlas and Amber head; clean alpha, proportional fitting and ground anchors.
- `src/environment.js`: cached sky, four parallax layers and asphalt.
- `src/rocket.js`: slow midground spaceport passage, launch/landing and recovery director.
- `src/spaceport-sprites.js`: single shared sprite atlas for hardware, exhaust, smoke, dust and explosions.
- `src/slapstick.js`: cosmetic Amber projectile with a bounded path behind the player.
- `src/loading.js`: nine-pose vector loader, real material readiness, timeout/retry and game reveal after the first complete scene.
- `src/main.js`: input, lifecycle, boost, score, composition and HUD integration.
- `style.css`: shared interface tokens, responsive layout and controls.

Hold and release the screen, Space, W or Up to jump; hold 0.4 s on the ground for full charge. The first jump plays a cosmetic kickflip. In flight, hold again to crouch, grab the Roadster and backflip; release for limited attitude assistance. Hold THRUST, B or either Shift for fuel-powered thrust away from the underbody, with an opt-in pressure-hiss recording. Touch supports simultaneous rotation and thrust. P/Escape pauses. Touch on UI buttons does not jump. Losing focus pauses the game. Local-only `window.__qa` exposes controlled test state; production exposes only a read-only JSON snapshot through `render_game_to_text()`.

## Balance and rendering

Start: 130 km/h (360 logical units/s), ramp to 400 km/h over 150 progression seconds. Earned landing streaks add up to 25% speed. Recovery freezes progression and restores the pre-fall cruise speed. Camera range expands smoothly without repositioning obstacles. Validated templates replace the legacy normal-tap pair generator. Ordinary human obstacles are 94 units; Rogozin plus trampoline and peak bounce is 130 units. Collision boxes remain slightly inset and have no hidden charge requirement.

Simulation rate is independent of display refresh rate. Render resolution is capped at DPR 1.5 for touch devices, 2 for desktop and a 3-million-pixel budget. Backgrounds and static props are cached; HUD refreshes at 10 Hz. Identical FPS across different hardware cannot be guaranteed; game time and physics remain identical at 30/60/120 FPS.
