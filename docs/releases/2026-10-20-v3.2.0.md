# 3.2.0 — Encounter collection

Adds the collection in the main menu and pause. Locked entries are noninteractive alpha silhouettes. Visible gameplay encounters unlock a card silently; collision on the same tick also counts. Discovery happens before death processing. Detailed portraits, fictional names/descriptions and basic properties reuse the current painters through a shared obstacle-art adapter. No new raster art or gameplay balance change.

NEW persists until the first successful detail display. Visiting the grid, repeated encounters and restarts do not clear it. First-view state survives reload; corrupt/future/blocked storage uses a session-only fallback without overwriting unknown save formats. Removing an obstacle from the current catalogue does not erase its saved history.

A native dialog provides focus containment. Browser Back/Forward and reload restore the appropriate overlay after material readiness. Game input is suppressed behind the dialog; closing returns to the menu or paused run, with an explicit resume action. Full 360-degree turntables remain an unfinished content stage; static portraits are not described as completed rotations.
