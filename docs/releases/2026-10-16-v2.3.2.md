# Release 2.3.2 — 16 October 2026

This release combines the completed local game updates on top of `331a970a2c3256856fbc3fe3fe287eea7584de37`.

- Muted midground spaceport; one sprite atlas for hardware, exhaust, smoke, landing dust and explosions. Launch and landing take 14 seconds; both failures recover through crawler replacement. Detonation preserves the actual rocket altitude.
- Nine video-derived Roadster flip poses remain intact. Grounded tyres meet the road; original photographed rims rotate from simulated speed. Body and Elon use a damped suspension on charge, takeoff and landing.
- Elon and Donny taunt with only their nearest hand: folded fingers and one raised middle finger, within 15 degrees of screen vertical (normally 10). Both angry faces and pupils track one another during approach, flip and departure. Body lean is compensated at the wrist. Elon retains the white X company logo.
- Opaque cached facial bases prevent double eyes or mouths during boost.

Validation before publication: `npm test` (16 tests), `npm run check`, syntax checks for changed JavaScript, and both rendered regression scripts against an isolated frozen copy. Character checks measure the final screen-space finger angle and pupil movement; Roadster checks cover real input, wheel contact, suspension, and accelerated integrated launch/landing/failure/delivery cycles. Desktop, portrait and landscape sizes are covered in Chromium. Real iPhone/Safari and hardware performance remain unverified.

The branch update must be a fast-forward from the expected parent above. Publication is confirmed separately by a successful GitHub Pages deployment and live version/resource checks; a Git commit alone is insufficient.

Rollback: create a new commit restoring the game files from the parent above, preserve any subsequent work, publish without force, then verify the Pages deployment and live resources. The frozen release input manifest and verification captures are retained locally. Historical archives and chat exports are not part of this public release.

The browser checks use an existing Playwright installation. `PLAYWRIGHT_MODULE`, `CHROMIUM_EXECUTABLE_PATH`, and `GAME_BASE_URL` select the installed tooling and the isolated test origin; no runtime dependencies were added.
