# 3.1.0 — Content foundation

First increment of the authorised upgrade sequence, published at the existing GitHub Pages game URL. Exact release state is identified by Git history and the Pages deployment; this document records candidate validation, not physical-phone acceptance.

`src/content.js` now owns all 19 obstacle definitions with the existing stable order, IDs and world geometry. It declares placement, bottom-centre anchors, renderer/material references, collision profiles, biome scope and independent hero/obstacle reactions. Legacy catalogue exports remain compatible. Rendering, gesture eligibility and trampoline collision dispatch consume these definitions. Gradual TypeScript checks cover the content contract; the browser still runs checked-in JavaScript with no new runtime dependency.

No new art, factory activation, balance change, collection, PWA or leaderboard is claimed by this release. Follow-on increments are tracked in `docs/UPGRADE-RELEASES.md`.
