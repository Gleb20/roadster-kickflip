Decisions

Play leads the menu. Collection has a separate upper card. Posting a verifiable finished score leads results. Pause keeps compact Continue, Restart and Home controls. The tutorial checkbox takes effect on the next explicit start.

Menu to collection

  1. 1Home

    Play, personal best and the actual server rank for a posted best. A separate collection card shows discovery progress.

    Primary: LET'S GO to run

    Collection opens the encounter files. Replay tips only prepares the next run; toggling does not start.
  2. 2Encounter files

    Locked silhouettes and discovered files. Opening a detail clears its NEW marker.

    Primary: open a file to its detail

    Close, Escape and Back return to the expected level. Forward and reload restore detail state.

Run to world ranking

  1. 1Pause

    Current score, optional posting of a saved finished best, Continue / Restart / Home. Unavailable posting is explained.

    Primary: POST PERSONAL BEST to the finished best's form

    The current run stays paused. Restart and Home end this attempt without posting it. The immutable verifier does not accept an unfinished replay.
  2. 2Finished run

    Prominent score, distinct personal-best celebration, posting CTA and secondary Retry / Home. A local run without a session promotes Retry.

    Primary: POST SCORE to nickname and explicit submission

  3. 3Verified score

    The server replays the run. Acceptance gives a public identity. View my rank highlights its exact row. Share score invokes native sharing or copies a public score link.

    A finished best can be posted after reload within 24 hours of session issue. A legacy best number without replay stays local; a rank is never fabricated.

Open questions and parked work

Posting an unfinished attempt would require a separate versioned ranking contract. An old number alone cannot reconstruct its replay. Posting lasts 24 hours from server session issue. An estimated rank for an unpublished score is not included; eligible bests instead offer explicit publication. Recorded route-search stalls and unfinished factory ramp, daylight and biome pools remain outside this task.

Static inspection, Chromium, disposable local server. Physical-device acceptance follows publication; see release verification for live deployment status.
