Сценарий

  1. 1. Земля

    Удерживать для заряда, отпустить для прыжка.

  2. 2. Полёт — удержание

    Компактный грэб, ускоренное сальто. Отпускание переводит в распрямление; повторное нажатие возвращает грэб.

  3. 3. Полёт — отпускание

    Ноги выпрямляются, вращение тормозится с сохранением инерции. Самонаведения к вертикали нет.

  4. 4. Касание

    До10°: PERFECT+50. До40°: безопасное приземление. Угловая скорость до240°/с в обоих случаях. Затем короткое приседание. Иначе: существующее падение/восстановление.
