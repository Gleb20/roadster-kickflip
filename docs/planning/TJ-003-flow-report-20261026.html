Accepted flow

A predictable protected course continues into the same ordinary run with its earned score. New players start training automatically. Returning players use an explicit replay. First useful success: clear an obstacle and land safely.

  1. 1Start playing

    Play opens the actual road. Existing start, best or legacy-tip evidence prevents automatic retraining. Replay training on next run is explicit.

    Play - driving scene.

  2. 2Perform one real action

    World time slows to 38%. The rider, relevant object, road and control stay bright; a finger/key shows hold and release. Seven fixed episodes: jump, charge, flip, thrust, rail, air, pickup.

    Normal controls - confirmed gameplay event.

    An error repeats only the current episode. Death and repeat-score farming are prevented by the shared simulation. The air lesson teaches driving underneath.
  3. 3Keep a successful skill

    Safe landing or the relevant event completes the lesson and saves progress. Each lesson awards 25 points once.

    Keep driving - next episode.

    Pause/hidden takes priority and clears held input. Reduced motion uses static finger phases.
  4. 4Continue the same run

    The full course keeps 175 points and the remaining collected score bonus. Normal generation resumes without restarting the run.

    Keep driving - ordinary ranked run.

    Skip training disables the whole course until explicit replay, keeps completed lesson points and clears controls. Practice time does not advance biome changes.
