Summary

A desktop workbench uses the same package contract and painters as the game. The user can inspect existing materials, download files, replace them, compare assembled results, then export a portable candidate. Draft import never publishes to the live game.

Flow: Inspect → replace → preview → export

  1. 1Library and inspector

    Select a biome, enemy, PNG or audio file. Inspector shows source size, fixed layout and world geometry. Search preserves selection.

    Primary action: Replace file → native file picker

  2. 2Validate replacement

    Check hash, file type, dimensions and decoding. Music checks duration; hearing decides quality. A failure retains the current draft and points to the required format.

    Primary action: Choose a corrected file → validated local draft

  3. 3Assembly preview

    Production renderers display the chosen biome and enemy. A real unranked full-cycle run and production music mix are available. Preview disables persistence, online ranking and service-worker activation.

    Primary action: Preview draft → isolated scene

  4. 4Portable export and restore

    All package descriptors and resource bytes export together. Import validates completely before replacing the draft. IndexedDB offers explicit restoration after reload.

    Primary action: Export package → .tjpack download
