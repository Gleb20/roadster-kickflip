# Current PWA kickflip icon (local3.7.1)

The active icon is a generated fictional game composition with a flat South Park-like in-game Elon, a video-derived silver Roadster in its roll, smoking thrusters, a diagonal flying rocket and two fictional street residents at the bottom. It replaces the earlier detailed San Francisco scene. No city/bridge artwork is included.

- Kickflip pose: Almonroth, [Skateboarding kickflip](https://commons.wikimedia.org/wiki/File:Skateboarding_kickflip.jpg), 8 December 2012, [CC BY-SA3.0](https://creativecommons.org/licenses/by-sa/3.0/). Pose and airborne/deck relationship adapted. The icon adaptation and resized derivatives are distributed under CC BY-SA3.0.
- Tucked-knee supplement: Paul Rodriguez, [Civil / Nike SB campaign](https://www.wearecivil.com/blogs/blog/nike-sb-p-rod-1-returns). Photographer/licence not stated; used as pose research/reference.
- Car: [Roadster Event - Tesla](https://www.youtube.com/watch?v=qt5p-_tE8d0), frame at689.890061 seconds, existing retouched video-derived game cutout frame8. The generator adapts the supplied car reference; the final composite is not an untouched video frame.
- Rocket: NASA/Bill Stafford, [Crew-8 launch](https://www.nasa.gov/blogs/spacestation/2024/03/03/liftoff-nasas-spacex-crew-8-begins-journey-to-international-space-station/). Reference for rocket/exhaust; diagonal flight and scene are fictional.
- Style: actual game hero/current screenshot and an official South Park TV still, source and research provenance retained in art-source/elon-grab-v351/brief.md. The TV frame is not a runtime asset.

Exact prompt, five supplied reference images, original and size review: art-source/pwa-kickflip-v2/. No endorsement implied.
