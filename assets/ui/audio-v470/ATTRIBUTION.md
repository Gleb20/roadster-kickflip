# Sound settings portraits

Five generated paper-cut Elon Musk head adaptations: muted / quiet / shush / neutral / loud. Created with built-in OpenAI image_gen, 23 October2026; original full-size PNGs and exact prompts are retained under `art-source/audio-controls-v470/`.

Likeness reference: **The Royal Society / Debbie Rowe**, [Elon Musk Royal Society portrait](https://commons.wikimedia.org/wiki/File:Elon_Musk_Royal_Society_(crop2).jpg) and linked full portrait, [CC BY-SA3.0](https://creativecommons.org/licenses/by-sa/3.0/). The existing project photo was inspected and passed to generation. These simplified paper expressions are adaptations, distributed under CC BY-SA3.0. Photo pixels are not used as runtime sprites. The style input is the actual game's existing paper hero.

Preparation: `sips` proportional downscale to192px; original alpha preserved, no stretching or semantic pixel repaint. Runtime animated pupils are separate code shapes. The cabinet, speaker cone and LEDs are authored native SVG extending the existing UI icon language; they are not a raster illustration or a branded product rendering.
