# Audio control artwork and motion brief

The user requests implementation, not an approval-only gallery. Five Elon head states: mute, 1–25%, 26–50%, 51–75%, 76–100%; 44 CSS px maximum. Every head has transparent paper cutout art and pupil-free white eyes; the browser overlays bounded tracking pupils. Mute is monochrome with a red hand over the mouth; quiet covers the mouth with a skin-coloured hand; shush has a single vertical index finger; neutral faces the player; loud is an excited wide-eyed open smile.

Real likeness reference: existing project photo `references/elon-royal-society.jpg`, verified against https://commons.wikimedia.org/wiki/File:Elon_Musk_Royal_Society_(crop2).jpg and its linked original full portrait. Source credits the Royal Society / Debbie Rowe, CC BY-SA 3.0. Existing older project credit mentioning Duncan.Hull is not reused as confirmed authorship. Use the Royal Society attribution and share-alike license for generated adaptations. Photo is reference only, never runtime art. Fresh April2022 photograph download returned403; it was not passed to generation.

Style reference: actual current game hero paper face, `references/game-hero.png`, same hero face still visible in the published4.5.0 screenshot. Native speaker icon extends existing SVG UI controls, with a cone, internal LED EQ and no brand prototype.

UI direction: existing navy paper-night surfaces, lime controls, cream text, steel hairlines; green/yellow/red only carry audio level meaning. Domain: rocket skate, pulse engines, arcade reward, paper Elon, telemetry, pit stop. Signature: tiny reacting Elon and dancing EQ beside real sliders. Preserve Play/Resume hierarchy and the existing circular pause button.

Motion thesis: one shared sound-to-pause control, origin-aware 220ms popover with restrained deceleration, faster140ms exit. Speaker: anticipation/squash before lift, stretch at apex, soft settle, secondary cone/LED motion; amplitude increases by quarter. Nonessential loops only on visible settings; reduced-motion gives static tier/LED states and centred pupils.
